# Sky widget assets

- `stars.csv`: stars to magnitude 4.0 from the HYG Database v4.1 (David Nash, astronexus/HYG-Database),
  CC BY-SA 4.0 — https://github.com/astronexus/HYG-Database. Reduced to right ascension, declination,
  magnitude and B-V; this derived file is shared under the same licence.
- Sky model: single scattering after wwwtyro/glsl-atmosphere (public domain), with the Earth constants and ozone
  layer of sebh/UnrealEngineSkyAtmosphere (MIT); night vision, star sizes, extinction, the Moon's shading and landscape
  lighting after Stellarium and Stellarium Web Engine (GPL-2.0+ / AGPL-3.0).
