# SeforimOpenSiddur

Powered by the technologies that drive Zayit — https://zayitapp.com/

מנוע פתוח לסידור החכם של זיתא. המנוע בונה רצף תפילות ליום האזרחי וללילה שאחריו לפי הנוסח, לוח השנה, המיקום והבחירות. היישום מספק את הטקסט ואת כותרות תוכן העניינים ממסד הספרים דרך `SiddurSource`. המנוע עצמו אינו זקוק למסד SQLite, לחיבור רשת או לחבילת הסידור הפרטית של זית.

## מקורות וכללים

- הנוסחים הם סידור אשכנז, סידור ספרד וסידור נוסח עדות המזרח. ראש השנה ויום כיפור, וכן המנחה בערב שלהם, משתמשים במחזורים המתאימים שבמסד. מנחה בערב יום כיפור כוללת את הווידוי שבתפילת הלחש.
- `CorpusSections.kt` ממפה תפילות לכותרות במקורות. `SiddurCalendar.kt` משתמש ב־KosherKotlin לחישובי לוח. `CorpusAnnotations.kt` מתייג קטעים לפי הוראות מפורשות בתוך הטקסט.
- תנאי פסקאות וחלופות מקורם ב־[Amud](https://github.com/Nt-f/amud/tree/c4327ead786ae15a1a80c946ebc2e34b5a345399/corpus). לפסקה שלמה יש תנאי משותף לכל חלקיה. לפסקה מעורבת, רק מקטעי HTML שלמים שהותאמו באופן חד־משמעי מקבלים תנאי. התוצר כולל טביעות SHA-256 ותנאים, והטקסט מגיע מהספרייה של המשתמש.
- `TorahReadings.kt` בוחר קריאות, מפטיר, הפטרות ומגילות לפי 14 סוגי השנים, ארץ ישראל או חו״ל, ובמקרים הרלוונטיים לפי מנהג עדות המזרח ועיר מוקפת חומה. הטבלה נוצרה מ־[Hebcal Leyning](https://github.com/hebcal/hebcal-leyning/tree/dc3e46a15ccf4e1bdc9802e32d7c807ffb8065b5). זיתא מציגה את הפסוקים מן המסד.
- `Selichot.kt` בוחר את סדר סליחות אלול ועשרת ימי תשובה לפי התאריך והנוסח. סדרי העונה שבמסד הם ליטא לאשכנז, פולין לספרד ועדות המזרח לנוסח עדות המזרח. בצומות קלים נבחרים הקטעים הייעודיים, וסליחות צום גדליה של ליטא ופולין מופיעות בסדר העונה.

## הרצה

נדרש JDK 25. לבדיקת המנוע יש להריץ `./gradlew jvmTest`, או `gradlew.bat jvmTest` ב־Windows.

אפשר לרענן את התיוגים מתוך העותק של Amud ומסד הספרים:

```sh
python tools/import_amud_annotations.py /path/to/amud /path/to/seforim.db
```

טבלת הקריאות ניתנת ליצירה חוזרת עם גרסאות Hebcal המוצמדות.

```sh
npm install --prefix /tmp/leyning @hebcal/leyning@10.1.0 @hebcal/core@6.14.4 @hebcal/hdate@0.23.1
node tools/generate_readings.mjs /tmp/leyning
```

## כיסוי

המנוע הוא שחזור עצמאי מהקוד הפתוח של מסך זית, מהספרייה ומהתיוגים של Amud. קריאות שכבר משובצות במחזורי ראש השנה ויום כיפור נשמרות בסדר המחזור. הטבלה כוללת את סדר הקריאה השנתי המקובל ואת חלופות ההפטרה שנתמכות ב־Hebcal. מנהגים מקומיים נוספים והוראות שאין להן התאמה חד־משמעית במסד עדיין מכוסים חלקית. לא בוצעה השוואה מלאה מול התוצר של מנוע זית הסגור.
